# Fanuc Control UI Kit (copia)

Copia sin modificar de `css/fanuc-ui.css` y `fonts/` del Fanuc Control UI Kit 1.0.
El servidor la publica en `/fui/`. Los ajustes propios del banco van en `static/tema.css`,
nunca aquí, para poder sustituir el kit por una versión nueva sin perder nada.

`js/fanuc-ui.js` no se usa: sus teclas 1-9 pulsan las teclas programables, y en el monitor
una pulsación suelta no debe cambiar de página.

Fuentes bajo SIL Open Font License 1.1: `fonts/LICENSE-ibm-plex.txt` y
`fonts/LICENSE-share-tech-mono.txt`.
